guest@charan:~$ help interaction

behaviour

boot only whoami is already run at load. Its last line, "run help to see commands", has help as a runnable token so touch visitors have something to tap. Then an empty prompt with the "type help" placeholder. Instant, no typing animation.

run every project or command name in output is a <button> that runs its command.

keys Enter runs. Tab completes only when there is something to complete, otherwise it moves focus (no keyboard trap). Up/Down walk history. Ctrl+L clears.

focus the prompt turns --ink and 800 weight while the input has focus. Buttons and links get a 2px --accent outline on focus-visible.

touch no auto-focus on coarse pointers, so the phone keyboard never opens uninvited.

motion none. No transitions, parallax, cursor effects or smooth scroll.
